# DomainListForMIMT

فهرست کامل و خودکار دامنه‌های ثبت شده در سامانه نماد تجارت الکترونیکی (ایران - MIMT) به همراه اطلاعات تماس، شماره تلفن، پست الکترونیکی، نام مالک، شهر، استان و وضعیت اعتبار اینماد.

## ویژگی‌ها

- رابط کاربری آنلاین در GitHub Pages جهت جستجو و فیلتر زنده
- فیلتر بر اساس استان، شهر، رتبه اینماد و وجود اطلاعات تماس (شماره تلفن / ایمیل)
- دانلود مستقیم کل داده‌ها در قالب فرمت‌های استاندارد CSV و JSON
- استخراج هوشمند اطلاعات شناسنامه کسب‌وکار از سرورهای Trustseal اینماد
- اسکریپت استخراج مداوم و حل خودکار کپچای سامانه

## ساختار فایل‌ها

- `index.html`: رابط کاربری وب اپلیکیشن و گیت‌هاب پیج
- `domains.json`: داده‌های استخراج شده با ساختار JSON
- `domains.csv`: فایل جدول اکسل با پشتیبانی از UTF-8 BOM
- `scraper.py`: اسکریپت استخراج، حل کپچا و واکشی اطلاعات تماس
- `enamad_data.db`: دیتابیس محلی SQLite جهت کش و پردازش بدون افت دیتا

## اجرای اسکریپت استخراج

برای ادامه یا بروزرسانی استخراج دامنه‌ها:

```bash
python3 scraper.py [تعداد_صفحات]
```

مثال برای استخراج ۱۰ صفحه بعدی:

```bash
python3 scraper.py 10
```
